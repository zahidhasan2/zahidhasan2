## 🛠️ Featured Projects

### ☁️ [3-Tier Application on AWS](https://github.com/zahidhasan2/BMI-Health-Tracker)
Three-tier web app (React, Node.js/Express, PostgreSQL) on a custom AWS VPC with public and private subnets, Internet Gateway, and NAT Gateway. Nginx is the single public reverse proxy, the backend runs with PM2 and systemd, setup is automated with Bash, and the private server is managed through a bastion host.
- **Tools:** AWS (VPC, EC2, NAT Gateway), Nginx, PM2, systemd, PostgreSQL, Bash, Linux

### 📈 [Monitoring 3-Tier Application](https://github.com/zahidhasan2/single-server-3-tier-webapp)
Containerized frontend, backend, and database with Docker Compose on a single server, plus Prometheus and Grafana dashboards for server, container, and application metrics, and Loki for centralized log aggregation.
- **Tools:** Docker, Docker Compose, Prometheus, Grafana, Loki, Nginx, Linux
